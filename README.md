# 我的第一个AI助手

## 项目介绍

这是我学习Python和人工智能时开发的第一个AI知识库助手。

它可以根据用户输入的问题，从知识库中查找答案。

## 项目功能

- 回答Python相关问题
- 回答GitHub相关问题
- 回答AI相关问题
- 回答Dify相关问题
- 回答机器学习相关问题
- 回答大模型相关问题

## 使用方法

1. 下载项目代码。
2. 使用Python运行main.py。
3. 根据提示输入问题。
4. 输入exit结束聊天。

## 使用技术

- Python
- GitHub

## 学习目标

通过这个项目学习Python编程、GitHub操作和AI应用开发。
